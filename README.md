## 📱 About This App

**Hayya Alal Salah** is a comprehensive Islamic education app that provides insightful lectures and guidance on Namaz (Salah). Whether you're a beginner or looking to perfect your prayer, this app provides the knowledge and inspiration to help you achieve spiritual growth.

### 🌟 Key Features

- **📚 Detailed Guidance**: Explore the significance of Namaz in Islam and its spiritual benefits
- **📖 Step-by-Step Instructions**: Learn how to perform each part of Namaz with clarity and precision
- **🔑 Key Aspects**: Understand the essential components and etiquettes of Namaz
- **📱 Learn Anywhere**: Access lectures and tutorials at your convenience to deepen your connection with your faith
- **💾 Video Caching**: Download and watch videos offline for uninterrupted learning
- **❤️ Favorites Section**: Save your favorite lectures for easy access
- **🎨 Modern UI/UX**: Clean, intuitive interface with light and dark theme support
- **🌐 Multi-Language Support**: Available in multiple languages for wider accessibility

### 📺 What's Included

- **Educational Videos**: High-quality lectures by Dr. Farhat Hashmi
- **Prayer Guidance**: Comprehensive instructions for performing Namaz
- **Islamic Knowledge**: Deep insights into Islamic teachings and practices
- **Offline Access**: Download content for learning without internet connection
- **Progress Tracking**: Keep track of your learning journey

## 🏗️ Development Setup

### Prerequisites
```bash
flutter --version  # Ensure Flutter 3.24.3+
dart --version     # Ensure Dart 3.5.0+
```

### Installation
```bash
# Clone the repository
git clone https://github.com/pakperegrine/hayya-al-salah-flutter-app.git
cd hayya-al-salah-flutter-app

# Install dependencies
flutter pub get

# Run the app
flutter run
```

### Build for Production
```bash
# Android
flutter build apk --release
flutter build appbundle --release

# iOS
flutter build ios --release
```
